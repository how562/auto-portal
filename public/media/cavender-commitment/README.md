# Cavender Commitment media

## Veterans video

Place the veterans testimonial video here:

- **Filename:** `veterans.mp4` (served at `/media/cavender-commitment/veterans.mp4`)
- **Recommended:** H.264 MP4, 16:9, 1080p or 720p

## Page background photos

The memo page backdrop uses photographic flags and saluting service members (not logos or icons):

| File | Use |
|------|-----|
| `backdrop-american-flag.jpg` | US flag |
| `backdrop-american-flag-2.jpg` | Alternate flag |
| `backdrop-soldier-salute.jpg` | Service member saluting |
| `backdrop-soldier-salute-2.jpg` | Alternate salute |

Replace these with your own Cavender-approved photography anytime; keep the same filenames or update paths in `lib/cavenderCommitmentBackdrop.ts`.
