# Lovable CMS handoff (temporary)

This folder is temporary for migrating Lovable CMS assets into the main app. Do not use in production.

## Layout

| Folder | Purpose |
|--------|---------|
| `raw/` | Drop the original zip export and `handoff.md` here |
| `extracted/` | Unpacked files for inspection and migration work |

## Workflow

1. Place the Lovable export zip and any notes in `raw/`.
2. Unpack the archive into `extracted/` for review.
3. Migrate assets and content into the main app as needed.
4. Remove this folder when migration is complete.
